# Mini Apps Hub

Ten small apps in a single HTML file, with no libraries or installs needed. Just open it in a browser.

## Apps

- To-Do list with filters and editing
- Notes with search and color tags
- Pomodoro focus timer
- Expense tracker with category totals
- Habit tracker with weekly streaks
- Memory card matching game
- Calculator with history
- Quiz game with score and timer
- Snake game
- Flashcards with flip and shuffle

## Features

- Dark and light theme toggle
- Mobile-friendly layout
- Data saved in the browser with localStorage

## How to run

Download the repo and open `index.html` in any browser.
